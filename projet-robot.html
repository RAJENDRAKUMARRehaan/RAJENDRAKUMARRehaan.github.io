Contexte

Dans le cadre d'un projet à l'ESILV, j'ai développé un robot Sumo autonome capable de détecter et pousser ses adversaires hors du ring. Pour aller plus loin, j'ai ajouté un système de contrôle à distance via WiFi , un serveur web embarqué directement sur l'Arduino.

Architecture du système

🌐

Interface Web

Page HTML servie par l'Arduino, avec boutons et gestion des touches clavier

⚡

API HTTP REST

Endpoints /cmd et /speed pour envoyer des commandes au robot en temps réel

🔧

Contrôle moteurs

Driver TB6612FNG contrôlant 2 moteurs DC + servo pour la lame

Ce que j'ai développé

  • Serveur HTTP embarqué sur Arduino UNO R4 WiFi (port 80)
  • Page HTML stockée en mémoire programme (PROGMEM) et servie à la demande
  • API REST avec parsing manuel des requêtes HTTP et des paramètres d'URL
  • Interface web responsive avec contrôle par boutons ET par clavier (touches numériques)
  • Slider de vitesse en temps réel via requêtes fetch JavaScript
  • Mécanisme de sécurité : arrêt automatique après 1 minute sans commande
// Exemple de parsing d'une requête HTTP // Reçu : "GET /cmd?c=f HTTP/1.1" String getParamFromRequest(const String& req, const String& key) { int q = req.indexOf('?'); String query = req.substring(q + 1, req.indexOf(' ', q)); int k = query.indexOf(key + "="); return query.substring(k + key.length() + 1); }

Ce projet m'a permis de comprendre concrètement comment fonctionne le protocole HTTP, comment parser des requêtes à la main, et comment exposer une API sur du matériel embarqué avec des ressources très limitées.
