Robot Sumo
Contrôle à distance

Date2025 – 2026
OutilsC++, HTML, JavaScript, Arduino
TypeProjet ESILV

Contexte

Dans le cadre d'un projet à l'ESILV, j'ai développé un robot Sumo autonome capable de détecter et pousser ses adversaires hors du ring. Pour aller plus loin, j'ai ajouté un système de contrôle à distance via WiFi avec un serveur web embarqué directement sur l'Arduino.

Ce que j'ai développé

  • Serveur HTTP embarqué sur Arduino UNO R4 WiFi
  • Page HTML générée directement par l'Arduino et accessible depuis n'importe quel navigateur sur le réseau
  • Contrôle des moteurs et du servo via des boutons ou le clavier
  • Parsing manuel des requêtes HTTP pour extraire les commandes reçues

Code complet

Serveur web et contrôle du robot
#include <WiFiS3.h> #include <Servo.h> const char* WIFI_SSID = "nom_du_reseau"; const char* WIFI_PASS = "mot_de_passe"; WiFiServer server(80); Servo monServo; // Broches moteur A const int PWMA = 3; const int AIN1 = 4; const int AIN2 = 2; // Broches moteur B const int PWMB = 9; const int BIN1 = 7; const int BIN2 = 8; // Servo et vitesse const int SERVO_PIN = 6; int angleServo = 90; const int VITESSE = 180; const int STBY = 5; void setup() { Serial.begin(115200); pinMode(PWMA, OUTPUT); pinMode(AIN1, OUTPUT); pinMode(AIN2, OUTPUT); pinMode(PWMB, OUTPUT); pinMode(BIN1, OUTPUT); pinMode(BIN2, OUTPUT); pinMode(STBY, OUTPUT); digitalWrite(STBY, HIGH); stopMoteurs(); monServo.attach(SERVO_PIN); monServo.write(angleServo); // Connexion au WiFi Serial.println("Connexion WiFi..."); while (WiFi.begin(WIFI_SSID, WIFI_PASS) != WL_CONNECTED) { delay(2000); } Serial.print("IP du robot : "); Serial.println(WiFi.localIP()); server.begin(); } void loop() { WiFiClient client = server.available(); if (!client) return; // Lecture de la requête HTTP String request = ""; while (client.connected()) { if (client.available()) { char c = client.read(); request += c; if (request.endsWith("\r\n\r\n")) break; } } // Commandes moteurs if (request.indexOf("GET /moteurA") >= 0) { moteurAAvant(VITESSE); stopMoteursB(); } else if (request.indexOf("GET /moteurB") >= 0) { stopMoteursA(); moteurBAvant(VITESSE); } else if (request.indexOf("GET /deux") >= 0) { moteurAAvant(VITESSE); moteurBAvant(VITESSE); } else if (request.indexOf("GET /different") >= 0) { moteurAAvant(100); moteurBAvant(220); } else if (request.indexOf("GET /stop") >= 0) { stopMoteurs(); } // Commandes servo else if (request.indexOf("GET /servoGauche") >= 0) { angleServo = max(0, angleServo - 10); monServo.write(angleServo); } else if (request.indexOf("GET /servoDroite") >= 0) { angleServo = min(180, angleServo + 10); monServo.write(angleServo); } else if (request.indexOf("GET /servoCentre") >= 0) { angleServo = 90; monServo.write(angleServo); } // Page HTML envoyée au navigateur client.println("HTTP/1.1 200 OK"); client.println("Content-Type: text/html; charset=UTF-8"); client.println("Connection: close"); client.println(); client.println("<!DOCTYPE html><html><head>"); client.println("<meta charset='UTF-8'>"); client.println("<style>body{font-family:Arial;text-align:center;margin-top:30px;}"); client.println("button{width:240px;height:55px;font-size:18px;margin:8px;}</style>"); client.println("<script>"); client.println("document.addEventListener('keydown',function(e){"); client.println("if(e.key=='a') window.location='/moteurA';"); client.println("if(e.key=='z') window.location='/moteurB';"); client.println("if(e.key=='e') window.location='/deux';"); client.println("if(e.key=='s') window.location='/stop';"); client.println("if(e.key=='ArrowLeft') window.location='/servoGauche';"); client.println("if(e.key=='ArrowRight') window.location='/servoDroite';"); client.println("if(e.key=='ArrowDown') window.location='/servoCentre';"); client.println("});</script></head><body>"); client.println("<h1>Controle Robot WiFi</h1>"); client.println("<p><a href='/moteurA'><button>Moteur A</button></a></p>"); client.println("<p><a href='/moteurB'><button>Moteur B</button></a></p>"); client.println("<p><a href='/deux'><button>Deux moteurs</button></a></p>"); client.println("<p><a href='/stop'><button>STOP</button></a></p>"); client.println("<p>Angle servo : " + String(angleServo) + "°</p>"); client.println("<p><a href='/servoGauche'><button>Servo Gauche</button></a></p>"); client.println("<p><a href='/servoDroite'><button>Servo Droite</button></a></p>"); client.println("<p><a href='/servoCentre'><button>Servo Centre</button></a></p>"); client.println("</body></html>"); delay(10); client.stop(); } // Fonctions moteurs void moteurAAvant(int v) { digitalWrite(AIN1,HIGH); digitalWrite(AIN2,LOW); analogWrite(PWMA,v); } void moteurBAvant(int v) { digitalWrite(BIN1,HIGH); digitalWrite(BIN2,LOW); analogWrite(PWMB,v); } void stopMoteursA() { analogWrite(PWMA,0); digitalWrite(AIN1,LOW); digitalWrite(AIN2,LOW); } void stopMoteursB() { analogWrite(PWMB,0); digitalWrite(BIN1,LOW); digitalWrite(BIN2,LOW); } void stopMoteurs() { stopMoteursA(); stopMoteursB(); }

Ce projet m'a permis de comprendre comment fonctionne le protocole HTTP en pratique, comment un navigateur communique avec un serveur, et comment embarquer tout ce système sur un microcontrôleur avec des ressources très limitées.
